# Changelog

All notable changes to this project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-10

### Added
- **Core 3D Canvas Grid**: Interactive custom particle network backdrop that responds to cursor movements in 3D perspective space.
- **Glassmorphic 3D Card Hover Tilts**: React component applying rotateX, rotateY, scale3d, and linear gradients dynamically.
- **Interactive Prompt Playground**: Syntax-highlighted variable tokenizers with side-by-side prompt version diffing and inline mock compiling.
- **Live Evaluator Suites**: Benchmark multiple prompt versions across customized test variable cases.
- **Evaluation Arenas**: side-by-side matrices comparing run outputs and metrics with native SVG dial charts and latencies indicators.
- **Custom Auth & RBAC Middleware**: Session token cookie encryption (HMAC SHA-256) and server-side RBAC (Owner, Member, Viewer).
- **Audit Logging Tracker**: Log creation triggers and runs with deep-dive action detail modals.
- **CSV Data Exporter**: Live streaming data table exporter to prevent 30-second gateway timeouts.
- **Custom 404 Navigation Router**: Glowing 404 screen with keyboard shortcut listener callbacks.
